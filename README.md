# RIXS pannler

軟X線 RIXS 測定計画のための、ブラウザで動くシミュレーターです。
XPS-Explorer の `menu` ブランチにある ARPES Cut Planner の画面構成と
XPS Energy Reference の内殻準位参照を参考にしています。

## 起動

外部パッケージのインストールやビルド、環境ファイルは不要です。

```powershell
node server.cjs
```

ブラウザで <http://127.0.0.1:8000> を開きます。停止は Ctrl+C。
`index.html` を直接開いても利用できます（自動保存はブラウザ依存）。
一般的な静的ホスティングにも配置可能です。

## 主な機能

- 左に運動量マップ、右に測定条件、条件欄内に配置図、下にスキャン・吸収端参照・スペクトル。
- Cu L₃ 初期値、軟X線中心の K / L₂ / L₃ 参照表、任意エネルギー入力。
- 入射／散乱角・tilt・面内方位・エネルギー損失から光子の運動量移行を計算。
- 立方晶・正方晶・斜方晶・六方晶・菱面体・単斜晶・三斜晶。対応する P/C/I/F/R 中心化格子。
- BZ の xy/xz/zy 投影とインタラクティブ3D表示。回転・パン・ズーム・タッチ操作。
- スキャンが通過する BZ の表示、Å⁻¹ / r.l.u. に連動する左上の運動量表示。
- H の等間隔スキャン（ΔH / r.l.u.）、測定点数・露光時間合計の自動計算、スキャン CSV、SVG マップ出力。
- 現象論スペクトルと角度–損失エネルギー強度マップ、それぞれの CSV 出力。
- 設定のブラウザ内自動保存、JSON 保存・読込、リセット。
- 英語を初期表示とする英語／日本語 UI、狭い画面対応、キーボードで測定点選択。

## 操作

ページ上部の Language から English / Japanese を切り替えます。HTML 本文と初回表示は英語です。選択言語をこのブラウザに保存します。説明・エラー・グラフ表示も切り替わり、測定条件やカメラは維持されます。CSV と設定 JSON の項目名は常に英語です。

1. Edge energy reference で元素を絞り込み、吸収端の「条件に適用」を選ぶと入射エネルギーだけが更新されます。Configuration ではエネルギーを直接入力できます。共鳴中心はモデルパラメータにあり、自動変更しません。
2. Configuration は入射光 → 散乱配置 → 結晶格子の順です。入射角スライダーと配置図も散乱配置にあり、結晶格子の左端のプルダウンで 2D / 3D を切り替えます。格子角・座標の定義は折りたたみ表示です。
3. Angular scan で角度範囲、H のステップ ΔH（常に r.l.u.）、運動量計算用 ΔE を設定します。点数と露光時間は自動計算されます。各単調区間の H 間隔は指定値で、端点・折り返し点を含む最後の間隔だけ短くなる場合があります（最大2,001点）。H が一定の配置は走査できません。開始角＝終了角で1点測定になります。
4. xy / xz / zy view は通常の視点ボタンです。3D のまま各面に正対でき、2D では表示面を選びます。ドラッグ／矢印キーで K 軸（Å⁻¹ では qᵧ）を上向きに保って回転します。通常の回転は上下 ±85° に制限します。xz 正対ボタンだけは K 軸方向から見下ろし、再度ドラッグすると通常の回転範囲に戻ります。パンボタンまたは右ドラッグで移動、ホイール／ピンチで拡大縮小できます。Shift＋矢印は測定点の選択、Home は視点リセットです。操作ボタンは現在の運動量表示の右側にあります。3D の現在点から奥の座標面へ破線を下ろし、その面に十字の投影線を表示します（ARPES カーソルと同じ方式）。投影線は単位・視点・配置に追従し、SVG 保存にも含まれます。
5. 分解能・損失範囲・共鳴中心などのモデルパラメータを調整してスペクトルを比較します。
6. CSV で計算結果、JSON で再現用設定を保存します。

入射角の操作モードは「2θ 固定」「L 固定」の2種類です。L 固定を選ぶと現在の L を保持し、入射角のスライダー・数値入力・マップ選択に合わせて 2θ を解きます。出射角の解が2つある場合は同じ枝を維持します。成立しない入射角は直前の配置を保持し、警告を表示します。エネルギー・tilt・格子・ΔE を編集した場合は、その配置の L を新しい固定値にします。
Angular scan も Configuration のモードに従います。2θ 固定では散乱角一定、L 固定では同じ出射枝で各入射角の 2θ を解き、指定した ΔE で L を一定に保ちます。走査可能な連続角度範囲を計算し、モード・配置変更時に開始／終了角を範囲内へ収めます。範囲内では従来どおり ΔH を指定できます。手入力で範囲を超えるとスキャン欄にエラーを表示します。
マップ、周辺 BZ、強度マップも同じ走査配置を使用し、スキャン CSV と強度マップ CSV には各点／列の散乱角を記録します。モデル分散は従来どおり、その配置の弾性近似を使います。

配置そのものが無効な入力時はグラフを消去して出力を停止し、自動保存しません。スキャン範囲や ΔH だけが無効な場合は、現在の配置・スペクトルを維持してスキャン出力のみ停止します。この場合も条件を保存でき、スキャン欄に修正箇所を表示します。
旧形式の点数指定 JSON は ΔH に移行して読み込みます（走査点は再計算）。CSV 冒頭の `#` 行に全設定を記録。強度マップはΔH とは独立した等角度101 × 240の表示グリッドです。

## 計算規約

`ħc = 1973.269804 eV Å`、`ki = Ei/(ħc)`、`kf = (Ei − ΔE)/(ħc)`。
`q = ki − kf` は試料に渡される波数ベクトルです。
表面法線は +z ∥ a₁ × a₂（直交晶・六方晶では c と平行）。α は入射光の進行方向を +x から下向きに測った角度、
β は出射光を +x から上向きに測った角度。散乱角 2θ は進行方向間の角度。
β = 2θ − α、0 < α, β < 180°、0 < 2θ ≤ 180°。

```text
q_parallel = ki cos α − kf cos β
q_normal   = −ki sin α − kf sin β
q_x        = q_parallel cos φ + q_normal sin τ sin φ
q_y        = q_parallel sin φ − q_normal sin τ cos φ
q_z        = q_normal cos τ
```

tilt τ は x 軸周り、続いて方位角 φ は z 軸周りの回転として q = Rz(φ) Rx(τ) q₀ に適用します。
φ = 0 の直交格子では、tilt を正にすると K が正側へ変わり、H は変わりません。
α・β と Configuration の配置図は tilt 適用前の散乱面内の設定角です。
表示の q∥ と CSV の qparallel はこの回転前の符号付き散乱面内成分、qz は回転後の結晶座標成分です。
ΔE は Eout を通じて kout と運動量マップ・スキャンに使います。スペクトルの横軸範囲とは独立です。

a 軸を φ = 0 とし、+z から見て反時計回りに方位角を回します。
実空間基底は a₁ を x、a₂ を xy 面に置き、指定した a/b/c と αcell/βcell/γcell から生成します。
結晶系に従属する長さ・角度は自動設定し、編集欄を無効にします。
P/C/I/F/R の中心化で primitive 基底を作り、その逆格子から真の3D Wigner–Seitz セルを計算します。
実空間が立方 I の BZ は菱形十二面体、立方 F は切頂八面体です。
菱面体軸はすでに primitive なので、R 中心化を重ねて適用しません。

H=q·a₁/2π、K=q·a₂/2π、L=q·a₃/2π。H/K/L は入力軸を基準とし、
菱面体は primitive 軸、他は conventional 軸です。
Å⁻¹ では物理的な Cartesian 成分と |q|・q∥・qz を左上に表示します。
r.l.u. では H/K/L 座標空間を描画し、左上の値・軸・ホバー表示も連動します。
斜交軸に対して √(H²+K²+L²) は物理的な大きさではないので、この擬似スカラーは表示しません。

「スキャン周辺の BZ」は、各点に最も近い逆格子点を中心とするセルを追加します。
セルの移動は厳密に逆格子ベクトルのみ。原点のセル Γ₀ は常に保持します。
点数が少ないスキャンも角度方向に補間して周辺セルを検索し、現在角度のセルを含めます。
最大4,097角度サンプル・256セルに制限し、上限到達時は画面に通知します。
極端な異方性や特異な格子は無効入力としてエラーを表示します。
任意の表面法線や屈折は未対応です。

## スペクトルモデルと限界

測定計画・分解能比較用の **現象論モデル** です。
第一原理や Kramers–Heisenberg の多体計算ではありません。

- Elastic：中心0、幅は分解能 FWHM。
- Phonon：指定位置、固有 Gaussian FWHM 15 meV。
- Dispersive：`D=sqrt((sin²(πH)+sin²(πK))/2)`、位置 `0.02+A D` eV、重み `w D`。
  H/K は弾性近似 q。特定物質のスピン波モデルではありません。
- dd / orbital：指定位置、固有 Gaussian FWHM 250 meV。
- ピークは面積規格化 Gaussian。装置分解能と固有幅は二乗和で合成。
- 共鳴因子は `1/[1+(2(Ei−E0)/Γ)²]`、Γ は共鳴 FWHM。
- 温度、偏光、行列要素、自己吸収、選択則、絶対計数、雑音は含みません。
- 元素を変更しても共通の仮想励起を使用し、元素固有のスペクトルを予測しません。
- 1D 表示は最大12,001点、強度マップは240エネルギー点。細いピークは損失範囲を狭めて確認してください。
- 露光時間は `点数 × 露光/点`。移動・読出し時間や必要 S/N は含みません。

## 検証

```powershell
node --test tests/model.test.cjs tests/ui.test.cjs
```

散乱角の解析式、非弾性余弦則、方位角、逆格子双対性、BZ 面積・境界、
Gaussian 規格化・FWHM、スキャン端点、スペクトルの整合性、無効入力を検証します。
55項目のテストが通過しています。UI テストは最小 DOM ハーネスを用い、
ΔH 等間隔・折り返し点・tilt・L 固定と到達不能条件、入力連動、単位表示、3D回転・パン・ピンチ、BZ切替、保存復元、CSV 内容、JSON 読込、エラー回復、英語／日本語切替、現在点の3D投影線、L 固定スキャンの範囲・ΔH・各点の散乱角を確認します。
実ブラウザの描画やレイアウトを検証するものではありません。

`node tests/browser.cjs` は Windows の Google Chrome を用いる任意の実ブラウザテストです。
ローカルサーバー起動後に実行します。専用プロファイル・ダウンロード・スクリーンショットは
リポジトリ内の `.browser-qa/` に保存します。
今回の実行環境ではブラウザ自動操作が `Page.enable` でタイムアウトしたため、実ブラウザテストと目視確認は未完了です。

## 構成

- `index.html` / `assets/css/app.css`：画面とスタイル
- `assets/js/lattice.js`：ARPES Cut Planner 由来の格子・Wigner–Seitz セル・最近接逆格子点の計算
- `assets/js/model.js`：RIXS 幾何・逆格子座標・スペクトル計算
- `assets/js/map.js`：2D/3D 描画、カメラ、マウス・キーボード・タッチ操作
- `assets/js/i18n.js`：英語／日本語の表示・言語設定
- `assets/js/reference.js`：出典付き内殻準位
- `assets/js/app.js`：描画・入力・保存・出力
- `server.cjs`：公開アプリファイルのみ配信
- `tests/model.test.cjs`：計算モデル検証
- `tests/ui.test.cjs`：画面ロジック・保存・出力の統合検証
- `tests/browser.cjs`：実ブラウザでの任意の検証

データはサーバーへ送信しません。外部ライブラリ、CDN、解析トラッカーは使用しません。
